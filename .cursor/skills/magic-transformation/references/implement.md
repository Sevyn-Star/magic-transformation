# 选定之后怎么做

配方里的 id 定下来以后，只读下面与这些 id 对应的节。数值以各条目的「细化」为准；这里补的是接法和失败时怎么办。任务带有页面规范时，先核对内容清单再接这些效果。规范里没有的块，不要为了接上某个动画补出来。

| 抽中的 id | 读这一节 |
|-----------|----------|
| `motion.fade-rise`、`motion.scale-in`、`motion.blur-in` | 滚动出现 |
| `motion.mask-reveal`、`motion.word-stagger`、`motion.kinetic-type` | 文字揭开 |
| `motion.marquee` | 跑马灯 |
| `motion.pin-story`、`motion.horizontal`、`motion.infinite-columns` | 滚动叙事 |
| `motion.shape-morph`、`motion.circle-reveal` | 形状裁切 |
| `motion.footer-reveal` | 页脚揭开 |
| `motion.video-scrub`、`motion.video-inview`、`layout.video-hero` | 影像 |
| `motion.coverflow` | 封面流转 |
| `motion.page-wipe` | 页面擦除 |
| `motion.smooth-scroll` | 平滑滚动 |
| `motion.pointer-trail`、`fx.cursor-shape`、`motion.cursor-spotlight` | 指针层 |
| `fx.goo`、`fx.liquid` | 黏连与液体 |
| `fx.edge-blur` | 边缘渐变模糊 |
| `fx.displace` | 局部置换 |
| `fx.metal-edge` | 金属边 |
| `fx.dither`、`fx.mesh`、`fx.grain` | 表面贴图 |
| `style.editorial`、`style.brutalist`、`style.minimal`、`style.glass-dark`、`style.blueprint` | 风格落地 |
| `layout.split`、`layout.image-grid`、`layout.cards` | 格子与分栏 |

任何会动的效果都先做静态第一帧，再把动效叠上去。

## 时间线

超过悬停变色的动画，只用一套时间线。简单显隐留在 CSS。

- 只动画 `transform` 和透明度。不要动画 `top`、`left`、`width`、`height`。
- 同一属性不要同时被 CSS 和脚本改。
- 进入类动画只播放一次。触发线大约在元素进入视口 20% 的时候。
- 字体和图片加载完成后再量一次位置。量早了，滚动触发会偏。
- 单页应用换路由或组件卸掉时，停掉这一页创建的时间线和滚动触发，解开监听。不要清掉别的页面还在用的实例。
- `prefers-reduced-motion: reduce`：不创建滚动擦洗、循环和视差，元素直接在终态。

桌面进入大约 0.6 到 0.9 秒，缓动用先快后慢。交错 0.05 到 0.08 秒，一组不要超过 8 个。

## 滚动出现

用交叉观察或滚动触发，二选一。

1. 元素加上「等待出现」的状态：透明度 0，向下 16px。导航和主按钮不要加。
2. 进入视口后去掉等待，加上最终状态。只观察一次。
3. 脚本没跑时，CSS 默认就是最终状态。等待状态只在脚本成功加上标记之后才生效。
4. 窄屏把位移减到 12px。减少动效时不要加等待状态。

## 文字揭开

遮罩只裁图片或装饰层。标题和按钮保持可选择。

逐词出现时，视觉上拆开的词对辅助技术隐藏，旁边留一整句不拆的文本。链接和按钮里面的字不拆。超过 12 个词就改成按行。

揭开时长 0.7 到 0.9 秒。主按钮在揭开结束前就能点。

## 跑马灯

一条轨道复制两份内容，用位移动画接成循环。速度大约每秒 40 到 60 像素。悬停和焦点时暂停。读屏只读一遍，第二份标记为隐藏。减少动效时改成可横向滚动的一行，不自动跑。

跑马灯不拿来放唯一的导航或唯一的价格。

## 滚动叙事

进度从滚动位置算出来，不要自己累加滚轮。否则拖滚动条、按 Home、刷新之后会对不上。

```
进度 = 已滚动距离 / (整页可滚动高度 - 视口高度)
```

钉住的那一节：外层留出足够的滚动高度，内层固定在视口里，内部步骤由进度切。步骤 2 到 4 个，每步有标题，并能用按钮直接跳到该步。不要劫持滚轮，系统滚动、触控和翻页键保持原样。

横向一排：垂直进度换成水平位移。结束之后回到正常的纵向页面。键盘左右键能移动。

减少动效：不钉住，各步改成上下普通排列。

离开页面时解除固定和监听。

## 平滑滚动

全站最多一个平滑滚动。它和滚动测量共用同一帧：滚动发生时刷新测量，而不是各跑各的。

图片和字体加载后重新测量。路由离开时销毁实例，并取消它注册的帧回调。

和章节吸附不要一起用。长文不要用。减少动效时用浏览器自己的滚动。

## 指针层

只在精细指针、悬停可用、用户没有要求减少动效时启用。触控和键盘不隐藏系统光标，也不留下拖尾。

拖尾层放在内容后面或旁边，`aria-hidden`，不要挡住链接。监听加在窗口上，层本身不吃点击。同时存在的拖尾点不超过 12 个，每个在大约 0.5 秒内消失。

区域离开屏幕、窗口失焦或页面隐藏时停止，不再创建新的点。减少动效或没有精细指针时，这一层不挂载，底下的内容就是完整的一帧。

自定义光标外形和拖尾可以同时存在，但表单字段里恢复系统光标。聚光若同时选了，只留一个暗角逻辑，不要两套叠在一起把页面涂黑。

## 黏连与液体

黏连用滤镜，不用一堆永远不会融合的模糊圆。

1. 一块区域内放 3 到 5 个圆形，区域尺寸固定。
2. 先高斯模糊，再用颜色矩阵把透明度对比拉高，重叠处就会连成一块。
3. 圆形只用 `transform` 移动。指针停下后大约 0.4 秒回到原位。
4. 文字和按钮不放进滤镜。

液体或黏连独占一块画面。失败、不支持或减少动效时，换成同一构图的静态色块或静态图。像素比不超过 1.5。离开屏幕或页面隐藏时停止渲染。

## 边缘渐变模糊

用在视口顶边或底边的一条，高度大约是视口的 12%。用来让固定导航底下的内容柔和过渡，不拿来模糊正文。

做法是叠几层只占这一条的遮罩：靠外缘模糊更强，靠内侧模糊降到 0。层不接收点击。放在内容之上、弹层之下。

背后没有东西可模糊时，改成一条实色渐变。用户偏好减少透明，或浏览器没有背景模糊时，同样改成实色。不要在阅读正文上做整页模糊。

## 金属边

只给一个物件或一条主按钮加一圈会缓慢变化的亮边。其余控件保持普通边框。

用伪元素画一圈渐变，再用遮罩挖空中间，只留下大约 1px 到 2px 的环。渐变角度慢慢转，一圈不少于 8 秒。离开屏幕或减少动效时停在当前角度，边还在，只是不转。

不要给每张卡片都加。对比不够时加一条实色底边，不要把字放进金属里。

## 表面贴图

抖动和颗粒在导出时做好，不要在滚动时对大图重算。纹理文件按 `SKILL.md` 的「背景」上网找来，不要用临时杂点冒充。网格渐变用页面里已有的两到三个颜色，静止，文字放在实色块上。

这三样不要叠在同一块区域上。用户不要装饰时，整层拿掉。

## 风格落地

选了主风格之后，按它的页面顺序做完一页，再把布局套进每一段。

- `style.editorial`：先给一张能站住的作品图和一句定位，再进入作品。工作室介绍放在作品之后。联系是最后一章，不要像附加上去的。
- `style.brutalist`：结构可以直接露出来，但正文不小于 16px，按钮不用悬停才看得到。
- `style.minimal`：一屏一件事。没有图就留白，不补装饰。
- `style.glass-dark`：深色底上只有一块或一条半透明面板。面板上的字用实色，不跟着玻璃一起变透。玻璃失败时改成实色面板。
- `style.blueprint`：细线只在图区。标注有编号，图下有一份同样的文字列表。

换掉任何参考里的名字、项目和图片。节奏可以借鉴。名字和事实用用户提供的。页面需要照片而用户没给文件时，按 `SKILL.md` 的「配图」和「裁切」上网找符合题材的，下载进站点，放进固定比例的画框，不引用站外地址。

## 格子与分栏

- `layout.split`：一边图一边字，顶端对齐。窄屏改成图在上、字在下。缺图时不要留半个空屏，改成单栏。
- `layout.image-grid`：图是主角，说明在图下并且始终可见，不靠悬停才出现。同一行顶边对齐。窄屏一列或两列。
- `layout.cards`：每张卡片字段相同。最后一行左对齐，不要把最后一张拉满。

格子间距全段统一。图片先写出宽高，避免加载后把按钮顶走。

## 形状裁切

裁切只作用于图，不作用于标题和按钮。进度若跟滚动，就从这一段的滚动位置算。进入时播一次的，播完就停在终态。

脚本没跑、或不支持裁切时，图完整可见，占位尺寸不变。

## 页脚揭开

先按普通文档排好页脚。只有脚本成功量到页脚高度后，才让正文盖住它。页脚比视口高，或窄屏高度会变，就保持普通排列。页脚里的链接不能只在揭开之后才存在于页面上。

## 影像

影像都要有海报帧和宽高。默认无声。离开屏幕或页面隐藏就暂停。

跟滚动走的进度只映射这一段，不累加滚轮，也不要再钉住另一段故事。没有用户提供的文件，就不要放空的播放器，也不要换一段别的素材。

减少动效时给出海报和控件，不自动播，也不跟滚动走。

## 封面流转

中间一项是当前项，标题在图外。左右键可用。不要自动旋转。和横向画廊、轮播只留一种横移。

减少动效或窄屏时改成列表或主图加小图，标题仍在。

## 页面擦除

只用于同一页里替换一整块视图。普通链接跳走时不要为了擦除推迟导航。擦除层在结束后移除。焦点落到新视图的标题或主内容。

减少动效时立即换内容。

## 局部置换

只歪一张图，幅度不超过图宽的 2%。指针离开后回到原图。文字、链接和按钮不在这一层里。

这块若用了画布，就不要再开液体、折射或粘连的画布。失败、减少动效和触控都显示原图。离开屏幕时停止。

## 卸载

离开页面时逐项检查：

- 时间线和滚动触发已停
- 平滑滚动已销毁
- 观察器已断开
- 画布已停止，并且不再持有纹理和渲染器
- 指针监听已移除
- 减少动效的监听已移除

## 弹层和选择

下拉、单选、多选、筛选、日期和弹出层按 `SKILL.md` 的「弹层和选择」自己画，不用系统菜单和系统对话框。

选择列表打开时，当前项在视口里。方向键移动焦点，回车选定，Esc 关闭并把焦点还给触发按钮。点列表外面也关闭。列表不要被页面滚动裁掉。

弹层打开时，后面的页面不再接收焦点。层内第一个可聚焦元素或标题获得焦点。关闭后焦点回到触发控件。窄屏的筛选层同样能用 Esc 和关闭按钮退出。

## 交稿前

- 脚本没运行时，标题、说明和主按钮已经在。
- 键盘能点到导航、按钮和表单，焦点看得见。下拉和弹层能打开、选定、关闭。
- 画框比例写死，同一组卡片等高。`object-position` 留住主体。
- 字号不超过五档，间距是 8 的倍数，节距大于节内距。第一屏只有一个主动作。
- 触控上没有只能靠悬停才出现的内容。
- 减少动效后没有钉住、没有循环、没有视差，内容是终态。
- 高成本画面失败时，页面上是静态替代，不是一块空白。
